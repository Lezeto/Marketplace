# Capturas de la landing

Coloca aquí 4 capturas de pantalla con **estos nombres exactos** (formato PNG).
Aparecen en la portada/login para explicar el proyecto sin necesidad de registrarse.
Mientras no existan, la landing muestra un marcador con el nombre del archivo esperado.

| Archivo | Qué debe mostrar |
|---|---|
| `01-home.png` | La **portada con la grilla de avisos** y el panel de filtros a la izquierda (tipo, categoría, región, comuna, precio). Idealmente con varios avisos publicados. |
| `02-detalle.png` | La **ficha de un aviso**: galería de fotos, precio, y la tarjeta del vendedor con las estrellas de reputación y los botones de contacto (Enviar mensaje / WhatsApp). |
| `03-publicar.png` | El **formulario de publicación** mostrando el selector Producto/Servicio arriba, las categorías y la zona de subida de fotos. |
| `04-mensajes.png` | La **mensajería**: la bandeja de conversaciones o un chat 1:1 abierto con burbujas. |

## Recomendaciones

- Tamaño sugerido: ancho ~1280 px (relación 16:10 se ve mejor; la landing recorta a esa proporción).
- Toma las capturas con la app ya poblada (publica 4–6 avisos de prueba antes) para que se vea con contenido real.
- Si prefieres otras vistas, puedes cambiar los textos y nombres en `src/views/AuthView.jsx` (constante `SHOTS`).
